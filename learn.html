Why the classroom is iOS first

The lesson is the screen.

You are learning to build the iPhone app, on the iPhone. Each module is a SwiftUI decision you can finish with a thumb, then see on the preview beside the code.

Principle 01

Read the SwiftUI first

The skill is spotting the line that breaks the screen, before you try to retype the view on a glass keyboard.

Principle 02

Visible cause and effect

Every token patch updates the live phone preview beside the snippet so beginners immediately connect syntax to runtime behavior.

Principle 03

Studio diffs become the next lesson

When the iOS studio ships a SwiftUI change, that hunk is the next drill. Compose lessons wait on the Android studio.
